## 本次修复

1. 登录成功后统一切换实时模式、加载服务器与设置，避免停在演示页或继续使用默认阈值。
2. 轮询实时网络汇总读取最新离线阈值，避免设置修改后仍按旧值计算在线节点。
3. 新建节点不再将探针 Token 填入管理员登录输入状态。
4. 部署文档纠正 AI 接口描述：当前固定使用 OpenAI 官方接口，不能填写自定义兼容接口地址。
