# 公开监控与后台管理

自托管版本访问首页会显示公开只读监控；点“后台登录”输入管理员账号后管理节点。退出后回到公开监控。管理员初次登录仍须修改默认密码。

公开范围：节点名称、分组、国家地区、运营商标识、系统、资源与网络指标、价格套餐、到期日期、近似地理坐标。不会返回服务器 IP、探针 Token、Telegram/OpenAI 密钥、私人备注、探测目标地址、操作记录或 AI 原文。公开接口固定读取自托管管理员的数据，不开放多租户 Sites 数据。任何配置修改仍要求身份验证。

## 卡片与浏览

默认紧凑卡片；一个按钮依次切换紧凑、完整、列表，保存在当前浏览器。支持搜索、地区、分组、名称/带宽/到期排序。后台手动排序仍保存为默认顺序。节点名称打开实时详情；公开地球可展开查看节点和线路，汇聚点选择只改变本次观看。

## 带宽与资产

实时带宽汇总在线节点上传与下载，离线数据不计入速率。累计流量是当前上报的开机网卡累计，不冒充完整账单。

资产按月度成本汇总，可展开选择 USD、CNY、GBP、EUR、USDT、USDC；年化为月费乘 12，免费节点不计费，一次性费用独立展示。使用 Coinbase 无需密钥的公开参考汇率接口，每 5 分钟获取，显示获取时间。稳定币采用接口实际返回值，不固定按美元等价计算。接口失败显示缓存过期或缺失，缺少币种时不展示不完整合计。参考汇率并非成交价格，不包含支付手续费。

官方接口说明：https://docs.cdp.coinbase.com/coinbase-business/track-apis/exchange-rates

今日统计采用 UTC 日期，只合计已保留、同次开机的连续采样计数差值，并显示采样速率峰值。接入前、删除记录、重启附近及当天首个采样前可能缺失；不会补造历史用量。表格独立滚动。

## 参考检查范围

参考 leafiel.com 公开首页的四项概览、地区/分组、排序、大/小卡片、节点详情中的资源与网络历史入口、今日流量及峰值表格。本次没有访问对方私人后台，也不宣称复制或验证对方全部隐藏功能。

## 更新现有 Nginx 部署

```bash
cd /opt/vpsbot/app && \
git pull --ff-only && \
docker compose -p vpsbot \
  -f deploy/vps/compose.yaml \
  -f /opt/vpsbot/nginx.override.yaml \
  up -d --build --no-deps panel
```

保留既有 Nginx、HTTPS 和端口映射，不启动占用 80/443 的 Caddy。此命令适用于已配置上述 override 文件的部署。
