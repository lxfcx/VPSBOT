# 公开监控与后台管理

自托管版本访问首页会显示公开只读监控；点“后台登录”输入管理员账号后管理节点。退出后回到公开监控。管理员初次登录仍须修改默认密码。

公开范围：节点名称、分组、国家地区、运营商标识、系统、资源与网络指标、价格套餐、到期日期、近似地理坐标。不会返回服务器 IP、探针 Token、Telegram/OpenAI 密钥、私人备注、探测目标地址、操作记录或 AI 原文。公开接口固定读取自托管管理员的数据，不开放多租户 Sites 数据。任何配置修改仍要求身份验证。

## 卡片与浏览

默认小卡片；一个按钮依次切换完整、小卡、迷你、列表，保存在当前浏览器。支持搜索、地区、分组、名称/带宽/到期排序。后台手动排序仍保存为默认顺序。节点名称或系统图标打开独立详情页，包含系统/资源/网络信息、负载与 Ping 图表，以及实时、1 小时、4 小时、1 天、7 天、30 天范围（按已有保留数据展示）；公开地球可展开查看节点和线路，汇聚点选择只改变本次观看。

## 带宽与资产

实时带宽汇总在线节点上传与下载，离线数据不计入速率。累计流量是当前上报的开机网卡累计，不冒充完整账单。

资产顶部按当前各节点已填写套餐价格换算合计（不是累计实付金额）；展开另列月度成本，可展开选择 USD、CNY、GBP、EUR、USDT、USDC；年化为月费乘 12，免费节点不计费，一次性费用独立展示。使用 Coinbase 无需密钥的公开参考汇率接口，每 5 分钟获取，显示获取时间。稳定币采用接口实际返回值，不固定按美元等价计算。接口失败显示缓存过期或缺失，Coinbase 失败时尝试 ExchangeRate-API 每日参考汇率并标注来源。缺少币种时保留各币种原价总额、明确标注待换算，绝不隐藏全部资产。参考汇率并非成交价格，不包含支付手续费。

官方接口说明：https://docs.cdp.coinbase.com/coinbase-business/track-apis/exchange-rates

今日统计采用 UTC 日期，只合计已保留、同次开机的连续采样计数差值，并显示采样速率峰值。接入前、删除记录、重启附近及当天首个采样前可能缺失；不会补造历史用量。表格独立滚动。

## 参考检查范围

参考 leafiel.com 公开首页的四项概览、地区/分组、排序、大/小卡片、节点详情中的资源与网络历史入口、今日流量及峰值表格。本次没有访问对方私人后台，也不宣称复制或验证对方全部隐藏功能。

## 更新现有 Nginx 部署

```bash
cd /opt/vpsbot/app && \
git pull --ff-only && \
docker compose -p vpsbot \
  -f deploy/vps/compose.yaml \
  -f /opt/vpsbot/nginx.override.yaml \
  up -d --build --no-deps panel
```

保留既有 Nginx、HTTPS 和端口映射，不启动占用 80/443 的 Caddy。此命令适用于已配置上述 override 文件的部署。


## 3 秒资源采样

前后台每 3 秒刷新最新指标；新版探针目标每 3 秒采集并上报，失败时退避。线路检测独立执行，每 10 秒更新，避免连接超时阻塞资源上报。网络耗时、外部通知等可能使实际间隔更长。旧探针不会随面板更新而自动替换，需在每台被监控服务器 SSH 执行：

```bash
curl -fsSL https://raw.githubusercontent.com/lxfcx/VPSBOT/main/agent/update.sh -o /tmp/vpsbot-agent-update.sh && sudo bash /tmp/vpsbot-agent-update.sh
```

此脚本保留现有探针配置和凭证，仅更新程序并重启 prism-agent。未安装探针的主机请从后台编辑节点部署。

桌面宽屏（1500px 起）完整/小卡四列、迷你五列；较窄屏幕自动减少列数。列表为横向指标表，窄屏可独立横向滚动。前台右上角低调登录图标进入后台，后台顶部“查看前台”切换为只读观看，不会退出账号。

累计流量来自最新上报网卡累计字节，与今日统计完全分开，1024 GB 自动显示 1 TB。该数值仍受服务器重启/网卡计数重置影响，不是服务商账单。

进度显示：CPU/内存/磁盘等使用较宽的圆角分段格，迷你视图减少格数以保持可读性；上传和下载使用独立短块格加实时指示，表达相对采样窗口峰值，而非虚构的套餐带宽占用率。断网时标明失联。资产汇率未就绪时，主金额区域直接显示各币种原价数值，避免隐藏资产金额。

资产渲染回归检查：`node scripts/test-fleet-ui.mjs`；此检查验证真实组件输出，不代替浏览器视觉检查。
